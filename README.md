# chessclock — 终端国际象棋钟

双人对弈计时器:基本用时 + 每步加秒,超时判负。纯 Python 标准库,单文件可跑。

## 安装

无需安装,Python 3.10+ 直接运行:

```bash
python -m chessclock 5+3
# 或
python chessclock.py 5+3
```

## 用法

```bash
chessclock 5+3        # 5 分钟包干, 每步加 3 秒
chessclock 10         # 10 分钟包干, 无加秒
chessclock 1:30+2     # 1 分 30 秒包干, 每步加 2 秒
chessclock --bullet   # 预设 1+1
chessclock --blitz    # 预设 3+2
chessclock --rapid    # 预设 10+5
```

时间制格式: `分钟[+加秒]` 或 `分:秒[+加秒]`,加秒单位为秒。

### 交互

| 输入 | 动作 |
| ---- | ---- |
| 回车(空行) | 换边(当前行棋方走完一步,加秒后换对方走) |
| 空格+回车 | 同上 |
| `q`+回车 | 中止对局 |
| Ctrl-C | 中止对局 |

开局**白方先行**,白方的钟先走。某方用时归零即超时,对方获胜。

## 设计取舍

- 计时用 `time.monotonic()` 单调时钟,不受系统时间调整(NTP/手动改时间)影响。
- 行输入模式:每一步需要按回车确认。这是为了**纯标准库、跨平台**(Windows 无 `termios`)的取舍;代价是换边有一次回车的延迟,见"已知局限"。
- 加秒在"换边"时一次性加给走完棋的一方,符合 FIDE/USCF 增量规则。
- 核心 `ChessClock` 类与界面解耦,可用注入的假时钟做单元测试。

## 已知局限

- **按键延迟**:行输入模式下,换边需要一次回车,延迟约等于一次终端行提交(通常 <50ms)。正式比赛请用实体棋钟或支持单键读取的终端程序。
- 显示刷新间隔 0.1 秒,百分秒显示为近似值。
- 无音效、无落子记录导出,中止的对局不保存。
- `q` 只在有输入时被读取;如果某方长时间不操作,超时判负仍然正常触发(靠 0.1s 轮询)。
